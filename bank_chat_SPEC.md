#Builds a banking chatbot that answers banking questions and calculates the cost in ₹.

##PURPOSE
Inform users about token consumption during their interaction with the banking chatbot.

##USER
Inform users about token consumption during their interaction with the banking chatbot.

##It must
- Calculate the number of tokens consumed by the user's interaction.
- Inform the user about the total token usage.
- Display token usage in a clear and understandable format.
- Provide updated token usage as the conversation progresses.

##It must not
- Display incorrect or misleading token counts.
- Confuse token count with word count or character count.
- Expose internal technical details to the user.
- Interrupt the user's conversation unnecessarily while displaying token usage.

#Done when
- Token usage is calculated accurately.
- The user is informed about the number of tokens consumed.
- Token usage is displayed in a user-friendly format.
- The displayed token count updates as the user continues interacting with the chatbot.
